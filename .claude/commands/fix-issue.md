# /project:fix-issue

Analise o problema descrito e:

1. Identifique o arquivo e a funcao afetada
2. Leia o codigo relevante e entenda o fluxo de dados (shapes, dtypes)
3. Proponha uma correcao minima que resolve o problema sem efeitos colaterais
4. Valide que os shapes permanecem consistentes apos a correcao
5. Se envolver GPU/CUDA, verifique implicacoes de memoria

Argumento: descricao do problema a ser resolvido.
